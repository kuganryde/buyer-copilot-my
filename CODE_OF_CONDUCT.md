# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and welcoming, give and accept constructive feedback gracefully, and put the people who'll rely on this tool first. Harassment, personal attacks and discriminatory language aren't tolerated in issues, pull requests, reviews or any other project space.

**Reporting:** if you experience or witness unacceptable behaviour, contact the repository owner privately through GitHub. All reports are reviewed promptly and kept confidential. Maintainers may remove, edit or reject contributions, and temporarily or permanently ban anyone whose behaviour is harmful, following the Covenant's enforcement guidelines.
